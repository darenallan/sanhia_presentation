# Sanhia — présentation

Présentation interactive (une page HTML) de **Sanhia**, la marketplace de boutiques locales du Burkina Faso : vision, produit, marché, architecture Firebase, identité visuelle « Obsidian & Gold », acquisition et feuille de route.

## Contenu

- `index.html` : la présentation
- `package.json` : script `build` qui copie la page dans `dist/`
- `render.yaml` : publication en site statique sur Render

## Lancer

```bash
npm run build   # produit dist/index.html
```

Ou ouvrir directement `index.html`. Projets liés : [`sanhia-web`](https://github.com/darenallan/sanhia-web), [`server-sanhia`](https://github.com/darenallan/server-sanhia).
